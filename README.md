# NAPE AICE 2026 Hackathon

**Theme:** Unlocking Dormant Value  
**Dates:** 7–8 November 2026  
**Venue:** Eko Hotel & Suites, Lagos, Nigeria

This repository contains participant resources for six finalist teams. Each team will work on **one assigned challenge**: Archive Digitisation or Archive Intelligence, using approved materials drawn from the publicly released Volve dataset.

## Start here
1. Review [draft competition rules](docs/competition-rules.md) and [data guidance](docs/data-access.md).
2. Read your assigned challenge under `challenges/`.
3. Use approved starter materials once published.
4. Follow the [submission guide](submission/README.md).

## Structure
- `docs/` — guidance and rules
- `challenges/` — two challenge briefs
- `shared/` — common resources
- `submission/` — templates and instructions
- `evaluation/` — public metrics and sample checks only
- `presentations/` — approved briefing materials

**Status:** Initial scaffold. Challenge specifications, final evaluation weights, IP terms and submission deadlines are subject to organiser approval.

No raw Volve data, confidential materials or API keys should be committed here.
