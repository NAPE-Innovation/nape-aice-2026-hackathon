# NAPE AICE 2026 Hackathon

**Theme:** Unlocking Dormant Value  
**Dates:** 7–8 November 2026  
**Venue:** Eko Hotel & Suites, Lagos, Nigeria

This repository contains participant resources for six finalist teams. Teams are allocated by witnessed lucky dip at kickoff, with three teams on each challenge. The approved challenge-specific Volve materials are provided on team laptops at the event; no raw dataset is committed here.

## Start here
1. Read the combined [Challenge Brief](CHALLENGE_BRIEF.md) for both tracks and their deliverables.
2. Review the [Competition Rules](docs/competition-rules.md) and [Data Access Guide](docs/data-access.md).
3. Follow the [Participant Technical Guide](docs/participant-technical-guide.md) and use the optional [Track 1](starter-kits/track-1/log_digitisation_starter.ipynb) or [Track 2](starter-kits/track-2/archive_intelligence_starter.ipynb) notebook for your allocated challenge.
4. Use the [Submission Guide](submission/SUBMISSION_GUIDE.md) and [Submission Template](submission/template/README.md).

## Repository structure
- `CHALLENGE_BRIEF.md` — one combined technical brief covering both challenges
- `docs/` — competition rules, data access and technical guidance
- `starter-kits/track-1/` and `starter-kits/track-2/` — optional starter notebooks
- `submission/` — instructions and inference submission template

**Release status:** Challenge Brief and submission mechanics remain subject to final organiser confirmation. Follow event-day announcements for approved environment, API permissions and deadlines.

Do not commit raw Volve data, organiser-only evaluation materials, confidential information or API keys.
